# Celebrity Face Match

Upload a selfie, get matched to the most similar celebrity face using FaceNet
embeddings + FAISS similarity search. Includes a FastAPI backend and a
Next.js frontend on top of the core ML pipeline.

See [DETAILS.md](DETAILS.md) for architecture and a file-by-file breakdown.

## Project Structure

```
celebrity-match/
├── data/
│   └── celebrities/          # one folder per celebrity, images inside (gitignored)
├── embeddings/
│   ├── index.faiss           # generated by build_index.py
│   └── labels.json           # generated by build_index.py
├── src/
│   ├── preprocess.py         # MTCNN face detection, align, crop to 160x160
│   ├── build_index.py        # embed all celeb images -> average per identity -> FAISS index
│   └── match.py              # embed query image, return top-5 matches (CLI + library)
├── api/
│   └── main.py                # FastAPI backend wrapping match.py (/health, /match)
├── frontend/                  # Next.js app: upload UI + ranked match cards
├── tests/
│   └── test_selfies/         # manually drop test images here
└── requirements.txt
```

## Setup

```bash
# Python (backend + ML pipeline) — requires Python 3.12
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# Frontend
cd frontend
npm install
```

> **Note:** if your system Python is newer than 3.12 (e.g. 3.13/3.14),
> `torch`/`facenet-pytorch`/`Pillow` may not have prebuilt wheels for it yet.
> Install Python 3.12 first (`brew install python@3.12` on macOS) and use it
> to create the venv.

## Build the index

Run once, and again whenever `data/celebrities/` changes:

```bash
source .venv/bin/activate
python src/build_index.py
```

## Running the app

Start the backend and frontend in two terminals:

```bash
# Terminal 1 — backend API (http://localhost:8000)
source .venv/bin/activate
uvicorn api.main:app --port 8000

# Terminal 2 — frontend (http://localhost:3000)
cd frontend
npm run dev
```

Then open **http://localhost:3000** and upload a selfie.

## CLI usage (no server needed)

```bash
source .venv/bin/activate
python src/match.py path/to/selfie.jpg
python src/match.py path/to/selfie.jpg --verbose   # show top-10 instead of top-5
```
